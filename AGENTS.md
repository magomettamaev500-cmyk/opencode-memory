# Протокол работы с памятью

Этот репозиторий — персистентная память агента. Он подключён как референс
`memory` и доступен по пути `~/opencode-memory`.

## В начале сессии

Прочитай `memory/preferences.md` и `memory/environment.md` — они задают способ
работы и контекст окружения. Читай остальное (`memory/profile.md`,
`memory/projects/`) только если задача это требует: не загружай всю память
целиком без надобности.

## Во время сессии

Записывай в память только то, что **не выводится из репозитория, который
сейчас правишь**, и что пригодится в следующих сессиях:

- факты о пользователе: роль, стиль, ограничения;
- предпочтения: стиль общения, стиль кода, рабочие ритуалы;
- факты об окружении: пути, версии, нестандартные настройки;
- решения, которые не видны из кода (почему так, а не иначе).

Не записывай: содержимое текущей задачи, очевидное из кода, секреты, ключи,
токены, `.env`, приватные данные.

### Куда писать

| Что выяснил                              | Куда                            |
| ----------------------------------------- | ------------------------------- |
| Факт о пользователе                      | `memory/profile.md`             |
| Предпочтение по стилю или процессу       | `memory/preferences.md`         |
| Факт об окружении                        | `memory/environment.md`         |
| Контекст по конкретному проекту          | `memory/projects/<имя>.md`      |
| Решение, контекст сессии, что делали     | `memory/log.md` (в конец)       |

## В конце сессии

Если в сессии появилась новая устойчивая информация — допиши её и
закоммить:

```powershell
cd $HOME\opencode-memory
git add -A
git commit -m "memory: <что записано>"
.\scripts\sync.ps1
```

`scripts/sync.ps1` делает `git pull --rebase`, затем `git push`. Если push
не прошёл (нет сети, нет прав) — не молчи: скажи об этом пользователю,
коммит при этом останется локально.

## Формат

- Факты — короткими маркированными списками, без воды.
- Один факт — один пункт. Не пиши прозу.
- Датируй журнал: заголовок `## YYYY-MM-DD — короткий заголовок`.
- Не переписывай историю журнала, дописывай в конец.
