# Предпочтения

## Общение

- Язык — русский. Отвечать на русском, если явно не сказано иное.
- Формулировки краткие, без воды. Без вступлений вида «Конечно!».
- Структура ответа: сначала результат, потом детали — по необходимости.
- Код и идентификаторы — английский, комментарии и обсуждение — русский.
- Технические термины не переводить без нужды (git, commit, ref, merge).

## Работа с кодом

- Не переписывать существующий код ради «улучшения» без запроса.
- Следовать стилю, который уже есть в проекте, а не собственному.
- Перед крупным рефакторингом — спросить.
- Удаление или перезапись чужой работы — только после подтверждения.

## Инструменты

- Для чтения файлов и поиска — специализированные инструменты, не shell.
- Shell — когда задача действительно командная.
- Не запускать команды, меняющие систему (установка пакетов, правки реестра,
  изменение системных настроек) без явного согласия.
- Не запускать интерактивные авторизации через shell — дать команду пользователю.

## Git

- Коммиты — короткие, императивные: `memory: add project notes`.
- Не пушить в чужие ветки и не переписывать историю без запроса.
