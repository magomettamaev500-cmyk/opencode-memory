# Молдовский язык с нуля — курс-сайт

- Путь: `C:\Users\rodio\OneDrive\Документы\Проект по умолчанию`
- Назначение: учебный сайт по молдовскому языку с аудио-озвучкой и тестами,
  запуск обычным HTML-файлом (по требованию пользователя).
- Состояние: рабочий, 2026-10-21. Версия 2 (3D-дизайн, 20 модулей).

## Состав

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка, точка входа |
| `css/styles.css` | 3D-стили: куб, переворачиваемые карточки, наклон за курсором, две темы |
| `js/data.js` | весь контент: 20 модулей, 229 слов + 34 доп., 126 вопросов |

| `dev-server.js` | статический сервер на чистом Node (порт 8123) |

## Ключевые решения

- **Классические скрипты, не ES-модули.** Иначе `file://` ломается из-за CORS.
- **Формат таблиц в `data.js` неоднороден**: строки бывают отдельными
  элементами `['tbl', head, row1, row2]` или одной вложенной группой
  `['tbl', head, [row1, row2]]`. Рендерер в `renderBlocks` различает оба
  варианта. Не «упрощать» одну из форм без правки рендерера.
- **Файлы озвучки ищутся по манифесту** `assets/audio/manifest.json`, а не
  опросом файловой системы: опрос давал бы до 2 секунд ожидания на фразу.
- **Транслитерация в имя файла** (`căsuță` → `casuta`) продублирована в
  `js/tts.js` (`slug`) и `tools/make-audio.ps1` (`Get-Slug`). Правки вносить
  в обоих местах.
- **Ответы сравниваются с нормализацией**: регистр, `ă/â→a`, `î→i`,
  `ș→s`, `ț→t`, лишние пробелы. Порог похожести 0.9.
- **Хранилище версионируется** (`version: 2` в объекте настроек). При смене
  дефолтов прогресс не теряется: старая версия мигрируется, дефолты обновляются.
- **3D-карточки слов**: `.wcard-wrap` (perspective) > `.wcard` (preserve-3d)
  > `.wface` (backface-visibility: hidden). Кнопка озвучки — **вне** `.wcard`,
  иначе вложенная кнопка внутри кнопки.

## Баги, найденные и закрытые (урок на будущее)

1. **`onStateChange` не был в экспортируемом API TTS.** Внутренний `state`
   модуля и внешний объект `TTS` — разные объекты, подписка молча терялась:
   бейдж голоса вечно показывал «🔊 …». **Правило: наружу отдавать сеттер,
   а не голое свойство.**
2. **`.note b { display: block }` ломал инлайновый `**жирный**`** внутри
   врезок — текст распадался на блоки. Лечится `.note > b`.
3. **Дублирующийся вариант ответа** в тесте (['râu','rîu','riul','rîu']) —
   проскочил структурную проверку. Проверять уникальность `opts`.
4. **`extra.known` = false vs undefined**: звёздочка «изучено» не рисовалась,
   потому что проверялась на truthy. Нужно `!== undefined`.
5. **Гонки в озвучке**: быстрые клики запускали две фразы. Решено счётчиком
   `token` — устареющая асинхронная цепочка прерывается.
6. **Chrome обрывает фразы длиннее ~15 секунд** — нужен keep-alive
   (`pause()`/`resume()` каждые 9 с).
7. **`prefers-reduced-motion: reduce`** в headless-браузере отключает анимацию
   куба — нужен статичный 3D-ракурс в том же медиазапросе, иначе куб
   выглядит плоским квадратом.

## Ограничения среды

- В системе **нет румынского голоса** — только `Microsoft Irina` (ru-RU) и
  `Microsoft Zira` (en-US). Озвучка работает, но звучит русским голосом.
- Установка румынского голоса требует прав администратора:
  `dism /online /add-capability /capabilityname:Language.Speech~~~ro-RO~`.
  Не выполнять без явного согласия пользователя.
- Chrome на машине не установлен. Встроенный в инструменты Chromium
  показывает те же два русских голоса.
- `SpeechRecognition` требует Chrome/Edge на ПК + сеть + разрешение на микрофон.

## Грабли

- **PowerShell 5.1 читает `.ps1` без BOM как ANSI** — кириллица ломается, а
  битые кавычки роняют разбор скрипта. Все `.ps1` с не-ASCII держать в
  UTF-8 **с BOM**.
- В консоли Windows кодовая страница 866 — русский текст выводится мусором.
  В скриптах помогает `[Console]::OutputEncoding = [Text.Encoding]::UTF8`.
- Браузерный инструмент не открывает `file://` — проверять только через
  локальный HTTP-сервер.
- Инструмент браузера не открывает `file://` и не показывает скриншот, если
  окно не в фокусе — переоткрывать вкладку и вызывать `tabs.focus`.
