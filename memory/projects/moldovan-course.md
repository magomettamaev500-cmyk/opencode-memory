## Голос — решёно без прав администратора

Румынского голоса в Windows нет, но нашлось решение лучше системного:

- **Edge TTS** (`edge-tts`, Python) — нейросетевой синтез Microsoft с
  румынскими голосами `ro-RO-AlinaNeural` (жен.) и `ro-RO-EmilNeural` (муж.).
  Без API-ключа, без установки голоса в систему.
- 474 фразы → 451 MP3, 6,2 МБ, ~2 минуты при конкурентности 8.
- Сайт играет их напрямую — офлайн, без задержек, с настоящим произношением.
- Бейдж в шапке показывает «🔊 нативный голос» (не «нет ro-голоса»).

**Грабли:**
- `msedge-tts` (npm, v2.1.0) **не поддерживает** токен `Sec-MS-GEC` — соединение
  зависает. Не использовать.
- `subprocess.check_output(..., text=True)` в Python читает в кодировке консоли
  → `UnicodeDecodeError` на кириллице. Обязательно `encoding="utf-8"`.
- `asyncio.ensure_future()` — иначе `coroutine object has no attribute 'done'`.
- Имя файла = slug фразы; алгоритм продублирован в `js/tts.js` (`slug`),
  `tools/generate_audio.py` (`slug`) и `tools/make-audio.ps1` (`Get-Slug`).
- **Записи из mp3 надо уметь останавливать**: `TTS.stop()` гасил только
  `speechSynthesis`, а mp3 продолжали играть и накладываться. Нужен
  `currentAudio` + `stopCurrentAudio()`.

## Ключевые решения по контенту

- **Курс написан латиницей — значит и алфавит надо учить латинский.** Первая
  версия учила кириллический алфавит Молдовы (33 буквы с э/ъ/ы), которого в
  курсе нет ни в одном слове. Переписана: 32 буквы, ă/â/î/ș/ț + ce/ci/ch/gh/șt,
  кириллица — только историческая справка (Приднестровье, закон 1990 г.).
- Правило «â → î» теперь соблюдается **везде** (было 4 нарушения в модулях
  16–19) — проверено скриптом по всем словам.
- «vreau» в Молдове → «vriu»: вычищено из всех фраз, включая эталоны
  аудиовопросов.
- Легенда транскрипции введена в модуле 2: a→а, e→э, i→и, o→о, u→у,
  ă→а/э, î→и, ș→ш, ț→ц, ce→че, ci→чи, ch→к, gh→г, j→ж.

## Дизайн-система (переписана с нуля)

Токены проверены по WCAG, замерено в браузере:

- **Шрифт:** 8 кеглей через `--fs-*` (было 25 значений), 3 веса (400/600/700),
  один h1 на страницу. Длина строки `--measure: 66ch` = **569 px** (было 1014 px
  = 125 знаков).
- **Контраст:** `--accent-text #7cb8ff` (9,4:1) для текста; `--accent-2` как
  текст запрещён (3,65:1). Светлая тема: `--ok #0f6b3a`, `--warn #8a5a00`
  (было 4,07 и 3,24 — FAIL).
- **Фокус:** `:focus-visible` 2px `--focus` на всём интерактивном (был
  невидимый UA-чёрный 1px).
- **Тени:** 3 ступени `--sh-1/2/3`, никаких «выдавленных» `0 Npx 0 rgba(0,0,0)`
  — они не работают в светлой теме.
- **360 px:** `.mods { grid-template-columns: minmax(0, 1fr) }` + `.mod { min-width: 0 }`
  — иначе неявная колонка `auto` брала min-content 714 px и layout viewport
  уезжал на 735 px (текст показывался в 49 % масштаба).
- **3D оставлен только там, где несёт смысл:** переворачиваемые карточки слов
  и куб. «Наклон за курсором» удалён: `:hover`-правила перебивали переменные
  `--rx/--ry`, эффект не работал никогда, а 3D-текст нечитаем.

## Грабли по инструментам

- **PowerShell 5.1 читает `.ps1` без BOM как ANSI** — кириллица ломается, битые
  кавычки роняют разбор. Все `.ps1` с не-ASCII держать в UTF-8 **с BOM**.
- В консоли Windows кодовая страница 866 — русский вывод мусором. Помогает
  `[Console]::OutputEncoding = [Text.Encoding]::UTF8`.
- **PowerShell ломает кавычки с кириллицей в `node -e`** — такие правки писать
  отдельным `.mjs`-файлом, а не инлайном.
- Браузерный инструмент не открывает `file://` — только локальный HTTP-сервер.
- `browser.screenshot` падает с «needs a visible tab», если окно не в фокусе.
- `location.hash = ...` из скрипта вызывает `hashchange` асинхронно: правки DOM
  сразу после могут быть затёрты перерисовкой. Вызывать `App.route()` явно.
