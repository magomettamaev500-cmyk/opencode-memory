# Проекты

По одному файлу на проект: `memory/projects/<имя>.md`.

## Что записывать

- Задача, ради которой велась работа (одной строкой).
- Принятые решения и их причины — то, чего нет в коде.
- Известные проблемы, грабли, неочевидные зависимости.
- Пути, команды сборки/запуска/тестов, если их нигде нет.

## Формат файла

```md
# <Название проекта>

- Путь: <путь к директории>

## Задачи

## Решения

## Заметки
```
