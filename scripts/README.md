# Синхронизация памяти с GitHub

Синхронизирует локальный клон памяти с удалённым репозиторием.

```powershell
cd $HOME\opencode-memory
.\scripts\sync.ps1
```

Что делает:

1. `git pull --rebase` — забирает изменения с GitHub, сохраняя локальные
   коммиты поверх.
2. `git push` — отправляет локальные коммиты.

Если push не удался, скрипт выводит текст ошибки и завершается с ненулевым
кодом — не проглатывай такую ошибку, сообщи пользователю.
