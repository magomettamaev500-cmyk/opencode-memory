# opencode-memory

Персистентная память OpenCode-агента. Хранит контекст, который не должен
теряться между сессиями: профиль пользователя, предпочтения, факты об
окружении, заметки по проектам и журнал решений.

Репозиторий: <https://github.com/magomettamaev500-cmyk/opencode-memory>

## Как это работает

Репозиторий подключён к OpenCode через секцию `references` в глобальном
конфиге (`~/.config/opencode/opencode.json`):

```jsonc
{
  "references": {
    "memory": {
      "path": "~/opencode-memory",
      "description": "Персистентная память: профиль, предпочтения, окружение, заметки по проектам. Читай в начале сессии, обновляй по мере уточнения."
    }
  }
}
```

Плюс `instructions` подключает `AGENTS.md` из этого репозитория, поэтому
протокол работы с памятью всегда в контексте.

Агент читает память как референс `memory` и пишет в неё через обычный git.

## Структура

| Файл                     | Содержимое                                              |
| ------------------------ | ------------------------------------------------------- |
| `AGENTS.md`              | Протокол: как читать и записывать память                 |
| `memory/profile.md`      | Кто пользователь: личный и рабочий контекст             |
| `memory/preferences.md`  | Предпочтения по общению, стилю кода и рабочим процессам |
| `memory/environment.md`  | Факты об окружении: ОС, инструменты, пути, конфиги      |
| `memory/projects/`       | Заметки по проектам, по одному файлу на проект          |
| `memory/log.md`          | Хронологический журнал сессий и решений                  |
| `scripts/sync.ps1`       | Синхронизация с GitHub (pull --rebase + push)            |

## Правила безопасности

В репозиторий **нельзя** класть: API-ключи, токены, пароли, содержимое
`.env`, приватные ключи. Только несекретные факты и заметки.

Публичный репозиторий — всё, что сюда попало, видно всем.
